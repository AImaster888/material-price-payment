# material-price-payment

台灣公共工程「估驗計價」文件逐項核算工具。給 Claude Code 用的 skill，也可以
單獨當 CLI 腳本用。

## 這個工具在解決什麼問題

估驗計價文件審查最容易出錯、也最容易被人工審查漏掉的幾件事：

1. **單價 × 本期數量 是否等於複價**——每一項逐列核對，不是只看小計。
2. **前期累計 + 本期完成 是否等於累計至本期**——同一份文件內部要自洽。
3. **前一期的「累計至本期」，是否等於本期的「前期累計」**——兩期文件的銜接
   數字，理論上一定要一樣，實務上常常因為忘記同步而對不起來。
4. **小計列的複價，是否等於底下所有子項複價的加總**——公式範圍拉錯很常見。
5. **兩份文件同一個數字，畫面上顯示出來是不是長得一樣**——這是最容易被忽略、
   但實際審查時最有感的一項：兩份不同人員製作的檔案，儲存格顯示格式（小數
   位數等）常常不一樣，即使底層數值數學上相等，畫面顯示出來可能完全不像
   同一回事，審查時會被質疑。詳見 [`docs/FORMATS.md`](docs/FORMATS.md)。

所有數字都是 Python 腳本用 openpyxl 讀出、算出來的，AI 只負責讀輸出、翻譯成
人話——不會有「AI 口算覆核」把錯的東西講成對的風險。

## 安裝（Claude Code）

```powershell
git clone <this-repo-url> D:\320code\material-price-payment
cd D:\320code\material-price-payment
.\setup.ps1
```

重啟 Claude Code，說「核對估驗計價」「跨期比對」之類的話就會觸發。

## 直接當 CLI 用

```bash
pip install -r requirements.txt

# 只核一份檔案（單價x數量、前期+本期=累計、子項加總反查）
python scripts/verify_payment.py 本期估驗計價.xlsx --sheet 請款明細表

# 兩份檔案一起核（再加上跨期銜接比對、畫面顯示文字比對），並輸出 md 報告
# 順序一定是「前一期在前、本期在後」
python scripts/verify_payment.py 前一期.xlsx 本期.xlsx --sheet 請款明細表 --md
```

`--sheet` 換成你要核的分頁名稱即可，欄位版型是自動偵測的（見下方「適用範圍」）。

## 適用範圍

適用於「橫向分成原契約／前期累計／本期完成／累計至本期幾個欄位群組」這種
台灣公共工程常見的估驗計價表格式。欄位的字母位置是自動偵測的（用標題文字
搜尋，不是寫死的欄位字母），所以不同機關、不同案子的範本大多可以直接用；
真的抓不到版型時，工具會清楚說明抓到什麼、缺什麼，方便手動排查或擴充。
細節見 [`docs/FORMATS.md`](docs/FORMATS.md)。
