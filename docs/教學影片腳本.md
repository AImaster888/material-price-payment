## 2-5　逐筆看異常：四種狀況（5:10–8:20）

開頭字卡：「好幾筆異常，常常是同一個原因」
旁白：計價總表報 8 筆，看起來很多，其實只有 3 個原因，再加 1 項沒核到。我們一個一個看。

### 狀況 A　前一期改了，本期沒跟著改

| 畫面 | 旁白 |
|---|---|
| 【錄】報告「跨期銜接比對」表格，標出物價調整、總計兩列 | 跨期比對抓到：物價調整金額，前一期累計 12,000，本期的前期累計卻是 12,500；總計也差 500。 |
| 02-A-第一期累計.png | 前一期這裡是修正後的 12,000。 |
| 03-A-第二期前期累計.png | 本期還留著修正前的 12,500，總計跟著差。 |
| 字卡：「差額一樣 → 同一個原因」 | 兩筆差額一樣都是 500，所以是同一件事，不是兩個問題。處理方式：先確認前一期的數字才是對的，再把本期的前期累計改過來，兩張表都要改。 |

### 狀況 B　公式被打成固定數字

| 畫面 | 旁白 |
|---|---|
| 【錄】報告「前期累計＋本期完成＝累計至本期（前一期）」交通工程費那列 | 第二種：同一份檔案自己加起來就不對。交通工程費，金額對，數量卻不對。 |
| 【錄】Excel 按 Ctrl＋`（數字 1 左邊那個鍵） | 回 Excel 按 Ctrl 加這個鍵，整張表會顯示公式。 |
| 04-B-固定值誤植.png，黃底 J8 閃一下 | 上一列 J7 是公式，J8 卻是固定數字 30——應該是 0.3，有人把 30% 打成 30。 |
| 字卡：「改回公式 → 另外兩處異常一起消失」 | 把這格改回公式就好。這一格也連帶讓跨期比對、畫面比對各報一次，改好會一起消失。 |

### 狀況 C　數字一樣，畫面長得不一樣

| 畫面 | 旁白 |
|---|---|
| 【錄】報告「畫面顯示文字比對」，原因欄「格式不同（數字相同）」 | 第三種，報告會直接標「格式不同、數字相同」。 |
| 05-C-第一期顯示.png 與 06-C-第二期顯示.png 左右並排 | 前一期顯示 0.37，本期顯示 0.367188，背後其實是同一個數。 |
| 【錄】Excel 選格 → Ctrl＋1 → 數值 → 小數位數 | 數字不用改，Ctrl 加 1，把兩期同一欄的小數位數設成一樣就好。 |

### 狀況 D　出現「略過未檢查」⚠

| 畫面 | 旁白 |
|---|---|
| 【錄】報告中 ⚠ 略過那一行 | 最後一種：計價總表通常沒有單價欄，單價乘數量這項沒辦法核，會出現 ⚠。 |
| 字卡（紅）：「⚠ ≠ 核過沒問題」 | 這不是核過沒問題，是沒核到。這一項請人工抽查，或以請款明細表的結果為準。 |
| 字卡：「不核：稅、品管費、利潤、保險等百分比費用列；變更設計欄；手動加總小計」 | 另外這幾種它也不核，請人工驗算。 |
